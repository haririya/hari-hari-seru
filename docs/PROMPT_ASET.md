## ATURAN MAIN (baca dulu, ini yang menentukan hasil rapi atau tidak)

1. **Tempel STYLE BIBLE di awal setiap prompt.** Jangan diringkas, jangan diubah. Kalau diubah, gaya antar gambar akan beda dan game terasa tidak menyatu.
2. **Rasio 1:1 (square)** untuk semua gambar.
3. **Latar putih polos** — bukan transparan. Latar putih nanti saya hapus otomatis.
4. **Satu objek satu gambar.** Jangan minta beberapa karakter sekaligus.
5. **Tanpa bayangan.** Bayangan lembut gagal dihapus dan meninggalkan kotak abu-abu di game.
6. **Generate 1 unicorn dulu**, kirim ke saya, saya cek. Kalau sudah pas, baru lanjut sisanya. Jangan generate 14 sekaligus sebelum gaya pertama disetujui.

```
2D cute children's book vector illustration, bright pastel colors, clean flat style, thick soft dark outline, simple flat shading, isolated on plain pure white background, no drop shadow, no ground shadow, no gradient background, no text, no letters, no border, no frame, single character centered and large with clear margin around it, square 1:1 composition
```

## D. YANG TIDAK PERLU DIGENERATE

Ini saya buat sendiri dengan SVG/CSS karena hasilnya lebih tajam dan tidak perlu kamu kerjakan:

| Elemen | Alasan |
|---|---|
| Rintangan (kristal, batang kayu, sungai, gerbang, awan) | bentuk geometris sederhana |
| Bentuk (lingkaran, segitiga, kotak, bintang, hati) | harus presisi, SVG lebih rapi |
| Latar parallax (bukit, langit, awan, pelangi) | dibuat bergerak dengan CSS, tidak bisa pakai gambar diam |

## E. KALAU HASILNYA MELESET

| Masalah | Tambahkan ke prompt |
|---|---|
| Ada bayangan di bawah karakter | `absolutely no shadow under the character, character floats on pure white` |
| Latar tidak putih rata / ada gradien | `flat pure white #FFFFFF background, completely uniform, no vignette` |
| Karakter terpotong di tepi | `entire body fully visible inside the frame with wide empty margin on all sides` |
| Muncul teks atau tulisan aneh | `no text, no letters, no numbers, no watermark anywhere` |
| Gaya terlalu 3D / realistic | `strictly flat 2D vector, not 3D, not rendered, no photorealism, no texture` |
| Karakter menghadap kiri (untuk unicorn) | `facing right, running towards the right side of the image` |
| Ada dua karakter / duplikat | `exactly one single character, no duplicates, no reflection` |
